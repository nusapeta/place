# placeid 0.1.0

Rilis kandidat v1, 2026-11-13.

## Isi

- Builder PBF ke index mmap format v1 untuk Indonesia.
- Server HTTP read-only: `/search`, `/reverse`, `/lookup`, `/healthz`,
  `/version`, `/metrics`.
- Index penuh 141.997.032 B dari PBF 1.741.650.872 B, 1.226.755 fitur.
- Reverse centroid dengan radius default 1000 m.
- Container Debian bookworm-slim, UID 65532, read-only, batas 512 MB.
- Prometheus metrics, alert rules, dashboard, dan skrip promote/rollback.

`docker buildx build --platform linux/amd64 -t placeid:0.1 --load .`.

image tidak dipush. Image arm64 diuji lewat QEMU: health 200, search,
reverse, user 65532, dan root read-only.

ketiganya dipromosikan sebagai satu unit oleh `scripts/promote_release.sh`.

Manifest `index.sha256` adalah checksum isi yang ditulis builder; verifikasi
penuh memakai `--verify-checksum`.

## Deploy homelab

Rilis ini berjalan di `arifsani-pc1` sebagai project Compose `placeid`, port
loopback `127.0.0.1:18092`, alias jaringan `placeid` di `1panel-network`.
Index dibangun di mesin lain lalu dikirim sebagai artefak (puncak RSS build
8,2 GB tidak muat di 7,8 GB RAM host). Prosedur lengkap ada di
[deploy/README.md](../../deploy/README.md) dan `docs/OPERATIONS.md` §3.1a.

Akses publik memakai bundle gateway `routeid` di
`https://route.arifsani.xyz/place/*`, karena tunnel hanya punya rule untuk
hostname itu dan ingress-nya dicocokkan pada hostname asli. Gateway membuang
prefix sebelum meneruskan, memberi kuota 240/menit per IP (burst 40), dan
menutup `/place/metrics` dengan `404`.

Vhost openresty siap pakai untuk hostname khusus `place.arifsani.xyz` ada di
[`deploy/openresty/place.arifsani.xyz.conf`](../../deploy/openresty/place.arifsani.xyz.conf);
vhost itu menutup `/metrics` dengan `404` dan memberi `limit_req` 20 r/s per IP.
Hostname itu belum aktif: CNAME-nya sudah ada, tetapi tunnel belum punya rule
untuknya. Prosedurnya ada di [deploy/README.md](../../deploy/README.md) §4.2.

## Peningkatan

Belum ada versi sebelumnya. Index dan manifest harus dipromosikan bersama
sebagai satu unit; manifest tanpa index atau sebaliknya ditolak oleh
`scripts/promote_release.sh`.

## Batas yang diketahui

- Fuzzy tidak aktif default. Typo dan singkatan yang tidak dipetakan bisa
  tidak ditemukan.
- Reverse memakai centroid fitur, bukan interpolasi garis. Jalan panjang bisa
  melaporkan jarak hingga 167 m dari titik.
- Query `kota tua`, `tugu jogja`, `taman nasional komodo`, `sarinah`, dan
  `soetta` belum mencapai top-1 yang diinginkan; semuanya masuk top-5 kecuali
  `soetta`.
- Data admin hanya level 4 sampai 7 pada dataset ini; polygon admin tidak
  disimpan di index v1.
- Startup diukur setelah `posix_fadvise(DONTNEED)` pada file index, bukan
  setelah drop page cache global. Hasil 197,93 ms p50 adalah batas atas
  optimistis untuk cold boot penuh.
- arm64 diuji lewat emulasi QEMU, bukan hardware arm64 asli. Kinerja arm64
  tidak diklaim.

## Rollback

```bash
scripts/rollback_release.sh /srv/placeid
systemctl restart placeid
```

Simpan minimal dua rilis sebelumnya. Index lama tetap valid selama format
v1; server menolak format yang tidak dikenal.
