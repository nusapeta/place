# Nusapeta Place 0.2.1

Rilis 2026-11-20. Rilis patch: 0.2.0 memasang dua endpoint di bawah prefix
bundle, bukan di path yang didokumentasikan API.

## Perbaikan

- `GET /suggest` dan `GET /admin/reverse` terpasang di path yang
  didokumentasikan. 0.2.0 memasangnya sebagai `/place/suggest` dan
  `/place/admin/reverse`; gateway membuang `/place` sebelum meneruskan, jadi
  keduanya menjawab `404 route not found` pada deployment bundle.

## Perubahan

- Server mencetak alamat yang benar-benar di-bind, sehingga `--bind
  127.0.0.1:0` bisa dipakai pemanggil yang butuh port dari kernel. Test
  end-to-end memakainya agar tidak lagi berebut port bebas.

## Versi

| Komponen | Nilai |
|---|---|
| Server | 0.2.1 |
| Format index | 2 (pembaca masih menerima 1) |
| API | v1 |

Tidak ada rebuild index. Index dan manifest 0.2.0 tidak berubah dan tetap
menjadi rilis data terkini (`data-2026.11.1`).

## Instalasi

```bash
docker run --rm -p 127.0.0.1:8090:8090 -v "$PWD:/data:ro" \
  ghcr.io/nusapeta/place:0.2.1 \
  --index /data/places-v2-2026.11.idx \
  --manifest /data/places-v2-2026.11.idx.json \
  --verify-checksum
```

## Upgrade dari 0.2.0

Drop-in untuk binary dan image server. Pemanggil yang memanggil
`/place/suggest` atau `/place/admin/reverse` langsung ke geocoder (bukan lewat
gateway) harus memakai `/suggest` dan `/admin/reverse`.
