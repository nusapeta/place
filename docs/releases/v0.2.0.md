# Nusapeta Place 0.2.0

Rilis 2026-11-20. Perubahan terbesar: index format v2 dengan polygon admin dan
way line, sehingga reverse geocoding bisa mengembalikan alamat admin terdalam
dan jarak ke garis jalan, bukan hanya ke titik centroid.

## Isi

- `GET /suggest`: prefix walk di atas FST nama dan token yang sudah ada.
  Minimal 3 karakter, batas 2.000 baris, hasil jsonv2 dengan `match` dan
  `score`; bias jarak opsional lewat grid.
- `/reverse` mengukur jarak ke polyline way untuk jalan panjang dan
  mengembalikan `distance_m`.
- `GET /place/admin/reverse`: area admin terdalam dari data polygon, dengan
  hierarki, penanda `ambiguous`, dan `501 no_admin_polygons` bila index tidak
  membawa polygon admin.
- Index nasional format v2: 386.376.512 B dari PBF 1.741.650.872 B,
  1.226.755 fitur, 9.360 admin, 29.110.855 row postings.
- Idle RSS pada index v2 6,3 MiB (`RssAnon` 0,7 MiB), diukur 2026-11-20.

## Pasang

```bash
base=https://github.com/nusapeta/place/releases/download/data-2026.11.1
curl -fsSLO "$base/places-v2-2026.11.idx"
curl -fsSLO "$base/places-v2-2026.11.idx.json"
curl -fsSLO "$base/places-v2-2026.11.idx.sha256"
sha256sum -c places-v2-2026.11.idx.sha256
docker run --rm -p 127.0.0.1:8090:8090 -v "$PWD:/data:ro" \
  ghcr.io/nusapeta/place:0.2.0 \
  --index /data/places-v2-2026.11.idx \
  --manifest /data/places-v2-2026.11.idx.json \
  --verify-checksum
```

Index tidak ikut di rilis kode; hanya rilis data yang membawanya.

## Peningkatan

Index dan manifest harus dipromosikan bersama sebagai satu unit; manifest
tanpa index atau sebaliknya ditolak oleh `scripts/promote_release.sh`.

Server 0.2.0 menerima index v1 (flag section baru nol), tetapi fitur admin
polygon dan way line hanya aktif dengan index v2. Server 0.1.0 menolak index
v2 karena `format_version` 2. Rollback ke 0.1.0 berarti memasang kembali
index v1.

## Batas yang diketahui

- Fuzzy tidak aktif default. Typo dan singkatan yang tidak dipetakan bisa tidak
  ditemukan.
- Dedup nama hanya berdasarkan normalisasi string; tidak ada merge lintas
  entitas OSM.
- Data admin hanya level 4 sampai 7 pada dataset ini. 43 polygon admin gagal
  dirakit pada build ini dan tercatat di `warnings` manifest.
- Reverse memakai centroid untuk fitur pendek dan polyline untuk way di atas
  1000 m; interpolasi nomor rumah tetap tidak ada.
- arm64 diuji lewat emulasi QEMU, bukan hardware asli.
