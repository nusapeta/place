# Nusapeta Place 0.1.0

First public release. One mmap index, one binary, a read-only HTTP geocoder for
Indonesia.

## Included

- `nusa-place-build`: OSM PBF to one index file, format v1.
- `nusa-place`: `/search`, `/reverse`, `/lookup`, `/healthz`, `/version`,
  `/metrics`.
- Index of 1,226,755 features in 141,997,032 B, built from a 1,741,650,872 B
  PBF. Reverse uses feature centroids with a 1000 m default radius.
- Container image `ghcr.io/nusapeta/place:0.1.0`, amd64 and arm64, UID 65532,
  read-only root filesystem, 512 MB limit.
- Prometheus metrics, alert rules, dashboard, and promote/rollback scripts.

## Install

```bash
base=https://github.com/nusapeta/place/releases/download/data-2026.11
curl -LO "$base/places-2026.11.idx"
curl -LO "$base/places-2026.11.idx.json"
curl -LO "$base/places-2026.11.idx.sha256"
sha256sum -c places-2026.11.idx.sha256
./nusa-place --index places-2026.11.idx --manifest places-2026.11.idx.json \
  --verify-checksum --bind 127.0.0.1:8090
curl '127.0.0.1:8090/search?q=monas&limit=3'
```

The index does not ship inside the code release; only the data release carries
it. Consumer usage is in `docs/en/QUICKSTART.md`.

## Upgrading

There is no previous release. Promote the index and its manifest as one unit;
`scripts/promote_release.sh` rejects either file without the other.

## Known limitations

- Fuzzy matching is off by default; typos and unmapped abbreviations can miss.
- Reverse returns the feature centroid, not an interpolated street position.
  Long streets can be reported up to 167 m from the query point.
- Admin data covers levels 4 to 7 of this dataset; admin polygons are not stored
  in index v1.
- arm64 was exercised under QEMU emulation, not on arm64 hardware. No arm64
  performance is claimed.
- Startup timing was measured after `posix_fadvise(DONTNEED)` on the index file,
  not after dropping the global page cache; treat it as an optimistic bound for
  a full cold boot.
- `place_id` is an internal 64-bit identifier, not a Google Place ID.

## Rollback

```bash
scripts/rollback_release.sh /srv/nusapeta-place
systemctl restart nusapeta-place
```

Keep at least two previous releases. Older indexes stay valid while the format
version is 1; the server refuses a format version it does not know.
