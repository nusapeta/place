# Nusapeta Place 0.2.0

Released 2026-11-20. The headline change is index format v2 with admin polygons
and way lines, so reverse geocoding can return the deepest admin area and the
distance to a road polyline instead of only to a feature centroid.

## Included

- `GET /suggest`: prefix walk over the existing name and token FSTs. Minimum 3
  characters, 2,000-row cap, jsonv2 results with `match` and `score`, and an
  optional grid proximity bias.
- `/reverse` measures distance to stored way polylines for long roads and
  returns `distance_m`.
- `GET /admin/reverse`: deepest admin area from polygon data, with the
  hierarchy, an `ambiguous` marker, and `501 no_admin_polygons` when the index
  carries no admin polygons.
- National index, format v2: 386,376,512 B from a 1,741,650,872 B PBF,
  1,226,755 features, 9,360 admins, 29,110,855 posting rows.
- Idle RSS on the v2 index is 6.3 MiB (`RssAnon` 0.7 MiB), measured 2026-11-20.
- National build: 235 s and 7.87 GiB peak RSS on the test machine.

## Install

```bash
base=https://github.com/nusapeta/place/releases/download/data-2026.11.1
curl -fsSLO "$base/places-v2-2026.11.idx"
curl -fsSLO "$base/places-v2-2026.11.idx.json"
curl -fsSLO "$base/places-v2-2026.11.idx.sha256"
sha256sum -c places-v2-2026.11.idx.sha256
docker run --rm -p 127.0.0.1:8090:8090 -v "$PWD:/data:ro" \
  ghcr.io/nusapeta/place:0.2.0 \
  --index /data/places-v2-2026.11.idx \
  --manifest /data/places-v2-2026.11.idx.json \
  --verify-checksum
```

The index does not ship inside the code release; only the data release carries
it.

## Upgrading

Promote the index and its manifest as one unit; `scripts/promote_release.sh`
rejects either file without the other.

Server 0.2.0 accepts a v1 index (the new section flags are zero), but admin
polygons and way lines only work with a v2 index. Server 0.1.0 rejects a v2
index because `format_version` is 2. Rolling back to 0.1.0 means restoring the
v1 index.

## Known limitations

- Fuzzy matching is off by default; typos and unmapped abbreviations can miss.
- Name dedup is normalised-string equality only; there is no cross-entity merge.
- Admin data covers levels 4 to 7 in this dataset. 43 admin polygons failed to
  assemble in this build and are listed in the manifest `warnings`.
- Reverse uses the centroid for short features and a polyline for ways above
  1000 m; house-number interpolation is still absent.
- arm64 is tested under QEMU emulation, not on real hardware.
